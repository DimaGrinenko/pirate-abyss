## Adaptation and reproducibility

Run `node scripts/generate-pirate-audio.mjs` to reproduce the shipped audio without external tools. It copies selected complete original Ogg/Vorbis files byte-for-byte under the runtime event filenames. There is no conversion, trimming, synthesis, or modified file extension. The original ZIP files must already be extracted into their sibling `kenney-impact` and `kenney-interface` folders. No network downloads are performed.

`conversion-recipes.json`, written by the generator, identifies every selected original and records its complete time range, Ogg/Vorbis header metadata, output SHA-256 and byte-for-byte source equality. These checks validate the copy and container metadata; they are separate from browser decoding tests.

The optional `--enhance` mode requires a local FFmpeg executable on PATH, or specified by the `FFMPEG` environment variable. It creates layered versions under the same `.ogg` filenames. The script contains exact source selections, pitch changes, layer gains, delays, filters and encoding settings. In that mode, the recipe log also records the FFmpeg version, full arguments and PCM decode measurements. The shipped native-original mode does not require this enhancement.

The current runtime contains **11 Ogg/Vorbis files: two music loops and nine event sounds**. The event names are `click`, `reel-stop`, `spin-start`, `reel-loop`, `curtain-open`, `curtain-start`, `line-win`, `bonus`, and `laugh`. **`laugh.ogg` is a playful musical confirmation; it contains no human voice.** Additional quiet bell harmonics generated by Web Audio accompany special reveals and anticipation.

The former glass-and-water entrance cues are no longer shipped. The current bonus entrance and treasure celebrations arrange the retained CC0 sounds and Web Audio bell harmonics at their visible animation cues; pending notes are cancelled on mute, hidden tabs and skip. Their source selections, SHA-256 values and byte-for-byte original equality are recorded in `conversion-recipes.json`.

The source theme is used in full to preserve its intended musical loop. The selected droplet sound represents stylized magical water rather than a field recording of the ocean. Source archives and their licenses remain unmodified.

## Version 1.15 underwater music layer

**Underwater Ambient Pad** — isaiah658, CC0 1.0. Source: https://opengameart.org/content/underwater-ambient-pad . Original download: https://opengameart.org/sites/default/files/Underwater-Ambient-Pad-isaiah658_0.ogg (retrieved 2026-09-23). Saved as `underwater-ambient.ogg`, Ogg/Vorbis stereo, 44100 Hz, 16.671927 s. The complete original loop is copied byte-for-byte. It is streamed as a separate quiet music layer in bonus and celebration scenes; Web Audio gain envelopes crossfade it with the existing ship theme. No music is fetched from third-party servers at runtime. Original CC0 declaration and author identity were verified on the source page; attribution is retained voluntarily.
