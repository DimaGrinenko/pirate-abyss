# Fonts

Current v39 typography uses **Ruslan Display** by Oleg Snarsky, Denis Masharov and Vladimir Rabdu for carved cartoon headings/large bonus numerals, and **Bitter** by the Bitter Project Authors for ship-ledger UI text and readable financial amounts. Original complete fonts downloaded from the official Google Fonts repository on 2026-10-02; no third-party font requests at runtime, no font glyph modifications.

- https://github.com/google/fonts/tree/main/ofl/ruslandisplay — `ruslan-display.ttf`, original `RUSLAN-OFL.txt`.
- https://github.com/google/fonts/tree/main/ofl/bitter — `bitter-variable.ttf`, original `BITTER-OFL.txt`.

Both are distributed under SIL Open Font License 1.1. Earlier files below remain compatible authoring/legacy assets.

Yeseva One by Jovanny Lemonad is used for pirate display headings and large action labels. Golos Text by Alexandra Korolkova and Vitaly Kuzmin is used for live amounts, small labels and explanatory text. Both include Cyrillic and Latin; the complete local fonts are shipped rather than requested from a third-party font service at runtime.

Downloaded from the official Google Fonts repository on 2026-09-18:

- https://github.com/google/fonts/tree/main/ofl/yesevaone — `yeseva-one.ttf`, license `YESEVA-OFL.txt`.
- https://github.com/google/fonts/tree/main/ofl/golostext — `golos-text-variable.ttf`, license `GOLOS-OFL.txt`.

Both families are licensed under SIL Open Font License 1.1. The original files are unmodified. Earlier Rubik, Cormorant and Manrope files remain for compatibility with the historical styles.
